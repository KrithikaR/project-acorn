# project-acorn

SwiftUI + CloudKit iOS app for personal data tracking and milestone logging, developed with an AI-directed engineering process (staged design review, full test pyramid, CI).

## Status

Early development. Architecture and design docs in progress.

## Stack

- Swift / SwiftUI
- CloudKit (Apple, iCloud-backed sync)
- XCTest (unit, integration, UI)
- GitHub Actions (CI)
